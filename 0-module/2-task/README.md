# 🔍 Поиск элемента в массиве

> **Изучаем работу с массивами и циклами!** 📚  
> Эта задача познакомит вас с поиском элементов и обработкой граничных случаев.

## 🎯 Задача

Найдите **первое** (левое) вхождение числа **X** в массиве чисел. Если элемент не найден, верните **-1**.

```js
findElementInSequence(2, [1, 2, 3, 2, 4, 3]) === 1  // найден на позиции 1
findElementInSequence(12, [1, 2, 3, 2, 4, 3]) === -1 // не найден
```

> **⚠️ Примечание:** В условии упоминается "положительное число X", но код работает с любыми числами

## 🔍 Алгоритм поиска

```mermaid
    A[Начало: X и массив nums] --> B[Инициализация: index = -1]
    B --> C[Перебор элементов массива]

    D -->|Да| E{Это первое вхождение?}
```

| Параметр | Тип      | Описание                                    |
|----------|----------|---------------------------------------------|
| `x`      | `number` | Искомое число                              |
| `nums`   | `Array`  | Массив целых чисел (по модулю ≤ 1000)     |

## 🎓 Для новичков

**Что такое индекс массива?**  
Индекс — это позиция элемента в массиве, начиная с 0:
```js
const nums = [10, 20, 30];
//            ↑   ↑   ↑
//            0   1   2  ← индексы
```

**Почему возвращаем -1?**  
Это общепринятая практика в программировании — использовать -1 для обозначения "не найдено", так как это невалидный индекс массива.

## ⚡ Частые ошибки

❌ **Возврат последнего вхождения вместо первого**
```js
function findElementInSequence(x, nums) {
  let index = -1;
  for (let i = 0; i < nums.length; i++) {
    if (nums[i] === x) {
      index = i; // ❌ Перезаписывает каждое найденное!
    }
  }
  return index;
}
```

✅ **Правильно — остановка на первом найденном**
```js
function findElementInSequence(x, nums) {
  for (let i = 0; i < nums.length; i++) {
    if (nums[i] === x) {
      return i; // ✅ Возврат сразу при первом найденном
    }
  }
  return -1; // ✅ Если ничего не найдено
}
```
