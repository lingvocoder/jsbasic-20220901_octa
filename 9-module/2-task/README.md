# Учебный проект: Сбор проекта 

Это финальная задача по учебному проекту.
У нас уже есть все необходимые компоненты, и теперь мы объединим их одном полноценном приложении. 

Готовый проект можно посмотреть здесь — <https://course-jsbasic.javascript.ru>.
Создайте класс `Main`, который объединяет все компоненты проекта и отрисовывает их на странице. 

Важно помнить, что компоненты должны быть размещены на определенных местах на странице.
Мы заранее подготовили базовую верстку и специальные элементы, в которые мы будем вставлять компоненты. 

На вёрстку компонента можно посмотреть в файле в файле `index.html`, там же находится пример использования класса `Main`.

А на картинке ниже показано, как мы будем размещать компоненты на странице:

## Метод async render()

Реализуйте метод `async render()`, который показывает все компоненты магазина на странице и возвращает promise. 

Этот метод возвращает promise, так как блюда для отображения мы будем получать с сервера.

Ниже приведены требования к реализации метода.

### Создание базовых компонентов

Эти компоненты мы можем показать на странице сразу после вызова метода.

1. Создайте экземпляр класса `Carousel`, передав ему массив слайдов `slides`, и вставьте его корневой элемент внутрь элемента с атрибутом `data-carousel-holder`, который уже есть в разметке.

2. Создайте экземпляр класса `RibbonMenu`, передав ему массив категорий `categories`, и вставьте его корневой элемент внутрь элемента с атрибутом `data-ribbon-holder`, который уже есть в разметке.

3. Создайте экземпляр класса `StepSlider` для 5-и шагов с начальным значением 3 и вставьте его корневой элемент внутрь элемента с атрибутом `data-slider-holder`, который уже уже есть в разметке.

4. Создайте экземпляр класса `CartIcon` и вставьте его корневой элемент внутрь элемента с атрибутом `data-cart-icon-holder`, который уже есть в разметке.

5. Создайте экземпляр класса `Cart`, передав ему в качестве аргумента созданный ранее экземпляр класса `CartIcon`.

### Показ списка товаров

Список товаров для отображения хранится на сервере.
Чтобы его отобразить, нужно сделать запрос с помощью `fetch`.

1. Создайте запрос для получения товаров из файла `products.json`. Сервер отдает данные в формате `JSON`, поэтому вам нужно преобразовать результат после получения.

2. После получения массива товаров, создайте экземпляр класса `ProductsGrid`, передав ему в качестве аргумента массив товаров с сервера, и вставьте его корневой элемент внутрь элемента с атрибутом `data-products-grid-holder`, который уже есть в разметке. 

Также нужно не не забыть прописать `await` получения товаров, так как метод `render` возвращает promise. 

Обращаем ваше внимание, что в этом случае содержимое элемента, в который мы вставляем список товаров, нужно полностью очистить.
До получения товаров, мы отображаем "заглушки" (смотрите файл `index.html`).

### Фильтрация товаров после получения с сервера

После показа товаров, отфильтруйте их по текущим значениям фильтров.

Как вы помните, в нашем проекте предусмотрена фильтрация блюд. Мы уже реализовали слайдер для фильтрации по остроте. 

Помимо этого мы добавили в верстку два дополнительных чекбокса, которые призваны фильтровать блюда по критериям: `с орехами/без орехов` и `вегетарианские/не вегетарианские`. У этих чекбоксов добавлены `id` со значениями `nuts-checkbox` и `vegeterian-checkbox` соответственно.

В дальнейшем мы будем слушать событие изменения значения и фильтровать товары, но для начала нам нужно обновить список товаров по текущим значениям, вызвав метод `updateFilter`:

```js
//  this.productsGrid —  экземпляр класса ProductsGrid
//  this.stepSlider —  экземпляр класса StepSlider
//  this.ribbonMenu —  экземпляр класса RibbonMenu

this.productsGrid.updateFilter({
  noNuts: document.getElementById('nuts-checkbox').checked,
  vegeterianOnly: document.getElementById('vegeterian-checkbox').checked,
  maxSpiciness: this.stepSlider.value,
  category: this.ribbonMenu.value
});
```

Как вы видите значение категории и максимальной остроты для фильтрации мы берем из экземпляров компонентов `StepSlider` и `RibbonMenu` соответственно.

### Связь компонентов через события

Как вы помните, связь между компонентами в нашем проекте происходит через пользовательские события, такие как: `'product-add'`, `'slider-change'`, `'ribbon-select'`, `cart-changed`.

Добавьте обработчики на пользовательские события и изменения чекбоксов для фильтрации. 

**Пользовательские события:**

1. Если на элементе `body` происходит событие `'product-add'`, то нужно по `productId` из объекта события найти нужное блюдо в массиве блюд и добавить его в корзину, вызвав метод `addProduct` на экземпляре класса `Cart`.

2. Если на корневом элементе экземпляра класса `StepSlider` происходит событие `'slider-change'`, то нужно отфильтровать блюда по новому значению остроты, вызвав метод `updateFilter` на экземпляре класса `ProductsGrid`. Значение остроты мы берем из объекта события.

```js
//  this.productsGrid —  экземпляр класса ProductsGrid

this.productsGrid.updateFilter({
  maxSpiciness: value // значение остроты из события 'slider-change'
});
```

3. Если на корневом элементе экземпляра класса `RibbonMenu` происходит событие `'ribbon-select'`, то нужно отфильтровать блюда по новому значению категории, вызвав метод `updateFilter` на экземпляре класса `ProductsGrid`. Новую категорию, мы берем из объекта события.

```js
//  this.productsGrid —  экземпляр класса ProductsGrid

this.productsGrid.updateFilter({
  category: categoryId // категория из события 'ribbon-select'
});
```

Отслеживать события `'slider-change'` и `'ribbon-select'` можно также и на элементе `body`.

**Фильтрация при изменении значений чекбокосов:**

Для отслеживания изменений в чекбоксах `noNuts` и `vegeterianOnly` мы используем событие `change`.
Подробнее про него можно прочитать в статье [События: change, input, cut, copy, paste](https://learn.javascript.ru/events-change-input).

1. Если событие `change` происходит в чекбоксе с `id` `nuts-checkbox`, то нужно отфильтровать товары по критерию `с орехами/без орехов`:

```js
//  this.productsGrid —  экземпляр класса ProductsGrid

this.productsGrid.updateFilter({
  noNuts: checked // новое значение чекбокса
});
```

2. Если событие `change` происходит в чекбоксе с `id` `vegeterian-checkbox`, то нужно отфильтровать товары по критерию `вегетарианские/не вегетарианские`:

```js
//  this.productsGrid —  экземпляр класса ProductsGrid

this.productsGrid.updateFilter({
  vegeterianOnly: checked // новое значение чекбокса
});
```
